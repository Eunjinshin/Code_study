# Algorithm Practice

코딩 테스트 준비 및 자료구조/알고리즘 이론 학습을 위한 레포지토리입니다.

## 📁 Directory Structure

- `Theory/` : 자료구조 및 알고리즘 핵심 개념 정리
- `HackerRank/` : HackerRank 플랫폼 문제 풀이 (도메인 및 난이도별 분류)

## 🛠 Tech Stack
- Java, Python

## 📌 Commit Convention
- `feat`: 새로운 문제 풀이 추가
- `refactor`: 기존 풀이 코드 개선 및 최적화
- `docs`: 이론 정리 또는 README 수정
